# Melodio Touch Showcase Handoff

本目录是 Melodio 的 H5 开发预览副本(浏览器直接打开 index.html 可调试)。App 不内置任何专辑,素材一律通过文件夹导入。以下为早期 Album Preview Stage 的原始文档存档。

---

# Album Preview Stage v1.5 · 专辑试听演出器

一个无需安装、无需构建的纯 H5 专辑试听舞台。选择本地素材文件夹后，用快捷键切歌、换皮肤、全屏并隐藏控制 UI，然后直接录屏。


## v1.5 更新

- “曲图映射”升级为 **“曲目设置”**：每首歌可以同时指定图片和试听起点。
- 每首歌都有拖动时间尺、`mm:ss.s` 精确输入、`−5s / +5s` 微调与独立“试听”按钮。
- 打开曲目设置时会自动暂停正式演出，试听只播放约 8 秒，避免和舞台音频叠在一起。
- 起点修改后会同步到已预热的音频轨道；按 `R` 或重新切入该歌曲时会从新起点开始。
- 舞台底部时间改为从试听起点重新计算：例如源文件从 `01:20` 开始，画面仍从 `00:00` 计时。
- 导出的 `album.json` 会同时保存图片映射与每首歌的 `startAt`。

## v1.4 更新

- 新增 `↑` / `↓` 快捷键切换视觉皮肤：`↑` 上一套，`↓` 下一套；原有 `[` / `]` 仍可使用。
- 修复切歌时封面“渐入一次、回弹、又移动一次”的重复位移：现在只保留一次 360ms 入场，完成后无动画地接管到主封面层。
- 右上角不再读取或显示本地时间，仅保留当前皮肤名称。

## v1.3 更新

- 正式素材未配置 `subtitle` 时，不再显示“Listening fragment / 音频驱动视觉”等演示文案。
- 文件夹载入阶段会生成适合录屏的封面显示图与低分辨率背景图，避免大尺寸 PNG 在切歌瞬间触发解码和高斯模糊卡顿。
- 当前曲播放时会预热下一首音频；切歌时音频、歌名和图片在同一时刻进入切换。
- 黑胶唱片向右抽出，中心图片标签扩大，避免被方形封套遮住。

## v1.2 更新

- **歌名直接读取音频文件名**：推荐固定命名为 `01 歌名.wav`、`02 另一首歌.mp3`，页面会分别显示“歌名”“另一首歌”。
- **图片切换不再等待解码**：选择素材后会预先解码全部图片，切歌时画面和标题立即开始切换。
- **新增“曲图映射”面板**：点击底部“曲图映射”或按 `G`，可为每首歌单独选择使用哪张图片。
- **映射可以导出**：点击“导出 album.json”，把文件放回素材文件夹，下次载入会恢复对应关系。
- **封面改为唱片视觉**：左侧封面保持正向、稳定，不再被 FFT 推拉抖动；黑胶唱片从封套后方露出，播放时持续旋转。
- **FFT 仍然保留**：频谱、波形、背景光、粒子和瞬态反馈继续响应音乐，但不再驱动封面振动。

## 立即使用

1. 解压压缩包。
2. 使用最新版 Chrome 或 Edge 打开 `index.html`。
3. 点击“选择素材文件夹”。
4. 按空格播放，按方向键切歌。
5. 按 `G` 检查图片映射，并为每首歌设置试听起点。
6. 按 `H` 隐藏控制面板，按 `F` 全屏，然后开始录屏。

首次打开可以点击“先看演示”。演示使用 **5 首歌 + 2 张图片**。

## 文件命名

推荐使用这一种固定格式：

```text
MyAlbum/
├─ 01 歌名一.wav
├─ 02 歌名二.wav
├─ 03 歌名三.mp3
├─ 04 歌名四.mp3
├─ 05 歌名五.m4a
├─ 01.jpg
└─ 02.png
```

音频名前面的编号用于排序，编号后的文字直接作为画面中的歌名。

支持的常见音频：MP3、WAV、M4A、AAC、OGG、FLAC、OPUS。实际能否播放取决于浏览器，录制项目建议优先使用 MP3、WAV 或 M4A。

## 少图多歌

图片少于歌曲时，默认按连续章节分配，而不是 ABAB 循环：

```text
5 首歌 + 2 张图

歌曲 01 ┐
歌曲 02 ├─ 图片 01
歌曲 03 ┘

歌曲 04 ┐
歌曲 05 ┘─ 图片 02
```

载入后按 `G` 打开“曲目设置”，每一行都有图片下拉框，可随时改成任意对应关系。修改当前歌曲时，舞台会立即更新图片，不会重播音频。

## 设置试听起点

按 `G` 打开“曲目设置”。每首歌下方都有一条试听起点时间尺：

- 拖动圆点快速定位。
- 点击“试听”从当前起点播放约 8 秒，再点一次停止。
- 时间框支持输入 `01:23.5`，也可以直接输入秒数，例如 `83.5`。
- 使用 `−5s` / `+5s` 做快速微调。
- 修改完成后，正式切到该歌曲会直接从所选位置进入。

时间尺使用源音频的绝对位置；正式舞台的计时则从试听起点重新显示为 `00:00`，更适合录制成片。

## 保存映射

在“曲目设置”面板点击“导出 album.json”，下载得到的文件放回原素材文件夹。下次选择该文件夹时，页面会优先按配置恢复图片对应关系和试听起点。

示例：

```json
{
  "albumTitle": "专辑名称",
  "artist": "作者名称",
  "imagePolicy": "manual",
  "tracks": [
    {
      "audio": "01 歌名一.wav",
      "image": "01.jpg",
      "startAt": 32.5
    },
    {
      "audio": "02 歌名二.wav",
      "image": "02.png",
      "startAt": 18
    }
  ]
}
```

歌名仍以音频文件名为准，`album.json` 不需要重复填写 `title`。

## 三套视觉皮肤

- **邮票档案**：纸张网格、邮戳、印刷频谱和暖黑胶。
- **夜航胶片**：暗场电影排版、光泄漏、胶片噪点和高反光唱片。
- **玻璃潮汐**：深色玻璃、流体波形、粒子和冷色唱片。

三套皮肤都使用正向封面 + 旋转唱片结构，但边框、唱片材质、背景和 FFT 表现不同。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Space` | 播放 / 暂停 |
| `←` / `A` | 上一首 |
| `→` / `D` | 下一首 |
| `R` | 回到当前歌曲试听起点 |
| `↑` / `↓` | 切换视觉皮肤（上一套 / 下一套） |
| `[` / `]` | 切换视觉皮肤（兼容快捷键） |
| `G` | 打开 / 关闭曲目设置（图片与试听起点） |
| `M` | 动效强度：柔和 / 丰富 / 强烈 |
| `H` | 显示 / 隐藏控制面板 |
| `F` | 进入 / 退出全屏 |

## 录屏建议

- 浏览器缩放保持 100%。
- 推荐分辨率 1920×1080。
- 先在普通模式检查歌名、曲图映射和切换时机，再按 `H` 进入干净模式。
- 使用 OBS 时捕获浏览器窗口并启用桌面音频。
- 所有音乐和图片都在本地读取，不会上传。

## 使用 config.js 固定工程素材

选择文件夹是最方便的方式。若希望每次打开都自动加载固定素材：

1. 把歌曲放进 `assets/audio/`，图片放进 `assets/images/`。
2. 编辑 `config.js` 中的 `tracks`。
3. Windows 双击 `start.bat`，然后访问自动打开的网页。

使用本地服务器可以避免浏览器对 `file://` 相对媒体文件的限制。选择文件夹模式通常不需要服务器。
